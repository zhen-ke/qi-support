## 🌐 English

Welcome to the official support and feedback repository for **Qi (氣)**, a high-performance native macOS Go (Weiqi / Baduk) AI review and play application.

If you encounter any issues, find bugs, or have feature requests, please feel free to submit an issue or contact us.

### 📬 Contact & Support

- **Submit an Issue**: Click on the [Issues](https://github.com/zhen-ke/qi-support/issues) tab at the top of this repository to report bugs or submit feature suggestions.
- **Email Support**: Contact us via email at [xmit0806@outlook.com](mailto:xmit0806@outlook.com).

### ❓ Frequently Asked Questions (FAQ)

**Q1: What are the system requirements for Qi?**
**A**: Qi requires **macOS 14.0 (Sonoma)** or later. It is fully optimized for Apple Silicon (M1/M2/M3/M4) and Intel Macs with GPU acceleration.

**Q2: Do I need an internet connection or cloud tokens for AI review?**
**A**: **No.** Qi runs the KataGo AI engine locally on your Mac using Apple's Metal GPU framework. Analysis is 100% offline with zero subscription fees or cloud token limits.

**Q3: Which file formats are supported?**
**A**: Qi natively supports **.SGF** game files and features Finder Quick Look integration (press Spacebar in Finder to preview).

### ❓ 자주 묻는 질문 (FAQ)

**Q1: Qi의 시스템 요구 사항은 무엇인가요?**
**A**: **macOS 14.0 (Sonoma)** 이상이 필요합니다. Apple Silicon (M1/M2/M3/M4) 및 Intel Mac 환경에서 완벽하게 작동합니다.

**Q2: AI 복기를 사용하려면 인터넷 연결이나 추가 비용이 필요한가요?**
**A**: **아닙니다.** KataGo AI 엔진이 Metal GPU 가속을 통해 Mac 기기 내에서 100% 로컬로 구동되므로, 인터넷 연결 없이 무료로 무제한 사용할 수 있습니다.

**Q3: 어떤 기보 파일 형식을 지원하나요?**
**A**: **.SGF** 기보 파일을 기본 지원하며, Finder Quick Look(스페이스바로 미리보기) 기능이 통합되어 있습니다.
